# 站标

一颗带环的行星。「克拉克带」指地球同步轨道那条环带 —— 一条以科幻作家命名的
真实轨道，正好是这个站站的那道缝。环带这个意象同时接着站点背景图（卡西尼拍的
土星，见 `src/styles/glass.css`），所以两处视觉是一套。

## 唯一的源文件是 `public/favicon.svg`

另外两份都是从它派生的：

| 文件 | 用途 | 主题感知 |
| --- | --- | --- |
| `public/favicon.svg` | 现代浏览器的标签页图标 | ✅ 内嵌 `prefers-color-scheme` |
| `public/favicon.ico` | 老浏览器兜底（16/32/48 三档） | ❌ 浅色版 |
| `public/apple-touch-icon.png` | iOS「添加到主屏幕」，180×180 | ❌ 浅色版 |

**改了 SVG 就要重新生成后两份**，否则标签页和主屏图标会是两个不同的标。

## 重新生成

```bash
# 1. 从 SVG 栅格化出 ico 需要的三档 + iOS 那张
node -e "
const sharp=require('sharp'), fs=require('fs');
const svg=fs.readFileSync('public/favicon.svg');
(async()=>{
  for (const s of [16,32,48])
    await sharp(svg,{density:s*12}).resize(s,s).png().toFile(\`/tmp/ico-\${s}.png\`);
  // iOS 不支持透明，得自己铺底色；四周留 10px 边，图标不会顶到圆角
  await sharp(svg,{density:2160}).resize(160,160)
    .extend({top:10,bottom:10,left:10,right:10,background:'#e9eef7'})
    .flatten({background:'#e9eef7'}).png().toFile('public/apple-touch-icon.png');
})();
"

# 2. 打包成多尺寸 ico
magick /tmp/ico-16.png /tmp/ico-32.png /tmp/ico-48.png public/favicon.ico

# 3. 确认三档都在里面
magick identify public/favicon.ico
```

## 改设计时要知道的几件事

**XML 注释里不能出现 ASCII 双连字符。** 这一条是踩过的：注释里写了
`--foreground`（CSS 变量名），librsvg 直接拒绝解析整个文件：

```
XML parse error: Comment must not contain '--' (double-hyphen)
```

浏览器可能宽容，但 `sharp` / `magick` 这条栅格化链会当场失败。想在注释里
提 CSS 变量，就只写 `foreground`，别带前缀。

**环是用 mask 挖过的，不压在星球上。** 因为「环从星球前面穿过去」那种画法
需要靠底色描边才看得清，而底色随主题变，靠不住。挖掉之后只剩左右两片，
单色也能读。

**几个数值是为 16px 定的，别随手改小：**

- `stroke-width: 3` —— viewBox 是 32 宽，栅格到 16px 时这条线只有 1.5 物理像素。
  再细会被抗锯齿抹成一片灰，整个标只剩一个圆点。
- mask 圆 `r=9.8` 对星球 `r=7.8`，2px 的缝在 16px 下只剩 1 物理像素。
  再小环和星球就糊成一个椭圆了。
- 没画卫星光点。16px 下任何小于 2px 的细节只会变成一团脏点。

改完务必按三档看一遍（16 / 32 / 256），别只看大图。
