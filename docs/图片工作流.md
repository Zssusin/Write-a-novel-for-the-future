# 图片工作流：Cloudflare R2 外链

大量参考图**不放进 Git 仓库、不进 Astro 构建**，而是上传到 Cloudflare R2
（对象存储），文章里用外链引用。好处：

- 仓库一直很小，`git clone` / 构建都快，构建内存低。
- R2 **流量出站免费**（这是它比 S3 香的地方），配合 Cloudflare CDN 全球缓存。
- 图想加多少加多少，跟代码解耦。

> 代价：Astro 不会自动优化远程图。所以**上传前自己压一遍**（见下方第 4 节），
> 否则原图多大就下载多大。

---

## 1. 一次性设置（在 Cloudflare 控制台）

> 下面是功能名称，具体菜单位置 Cloudflare 偶尔会调，按名字找即可。

1. **建桶**：Dashboard → R2 → *Create bucket*，名字随意，比如 `scifi-blog-img`。
2. **公开访问**，二选一：
   - **快速试水**：桶 → Settings → 打开 *Public Development URL (r2.dev)*，
     会给你一个 `https://pub-xxxx.r2.dev` 地址。**有限速、Cloudflare 说别用于正式环境**，
     练手够用。
   - **正式推荐**：*Connect Custom Domain*，绑一个子域名，比如 `img.你的域名`
     （前提是这个主域名已经托管在 Cloudflare —— 你部署 Pages 时本来就会托管）。
     这样有 CDN 缓存、无限速、出站免费。**建议一开始就用这个，URL 就固定了，以后不用改文章。**
3. **建 API Token**（给上传工具用）：R2 → *Manage R2 API Tokens* → *Create API Token*，
   权限选 *Object Read & Write*。记下三样东西：
   - Access Key ID
   - Secret Access Key
   - S3 endpoint：`https://<账户ID>.r2.cloudflarestorage.com`

---

## 2. 批量上传（rclone —— 推荐）

`rclone` 最适合"一整个文件夹同步上去"。装好后配一次：

```bash
rclone config
# 交互里选：
#   n) 新建 remote，名字填 r2
#   Storage 选 s3
#   provider 选 Cloudflare
#   access_key_id / secret_access_key 填上一步的两个 key
#   region 填 auto
#   endpoint 填 https://<账户ID>.r2.cloudflarestorage.com
```

之后每次上传一整个目录：

```bash
# 把本地 ./图片准备好 里的东西同步到桶的 2026/ 目录下
rclone copy ./图片准备好 r2:scifi-blog-img/2026/ -P
```

> 只传一两张、临时用一下的话，也可以用 wrangler（你部署 Pages 会装它）：
> ```bash
> npx wrangler r2 object put scifi-blog-img/2026/foo.webp --file=./foo.webp
> ```

## 3. 在文章里引用

普通 Markdown，写完整外链就行（把域名换成你第 1 步绑的）：

```markdown
![戴森球示意图](https://img.你的域名/2026/dyson-sphere.webp)
```

就这么简单，不需要 import、不需要组件、不需要改 `astro.config`。

> 图多的时候（画廊那种），可以把文章后缀改成 `.mdx`，用 HTML 标签排版：
> ```html
> <figure>
>   <img src="https://img.你的域名/2026/a.webp" alt="..." loading="lazy" />
>   <figcaption>图注</figcaption>
> </figure>
> ```

## 4. 上传前压缩（重要！）

因为远程图 Astro 不会帮你优化，务必上传前转成 WebP 并限制尺寸，
否则页面会拖很慢。装 `sharp-cli` 后一条命令批量处理：

```bash
npx sharp-cli --input "./原图/*.{jpg,png}" --output ./图片准备好 \
  resize 1600 --withoutEnlargement \
  --format webp -- --quality 80
```

- `resize 1600` = 最长边压到 1600px（博客正文足够了）。
- `--withoutEnlargement` = 小图不放大。
- WebP quality 80 一般肉眼无损、体积砍到 1/3 ~ 1/5。

处理完的 `./图片准备好/` 再用第 2 节的 `rclone copy` 传上去。

---

## 5. 可选进阶（以后需要再说）

- **Cloudflare Image Transformations**：绑了自定义域名后，可以用
  `/cdn-cgi/image/width=800/<原图URL>` 这种链接**按需缩放**，就不用自己压多个尺寸了
  （有免费额度）。默认没开，需要时在 Dashboard 里启用。
- **让 Astro 优化远程图**：技术上可以在 `astro.config.ts` 加 `image.domains`，
  但那样构建时会去下载每张图再处理，**又慢又吃内存，等于把 R2 的好处抵消了**。
  所以这里故意不用——图片优化交给"上传前压缩 + Cloudflare CDN"。
