# 火星 2100 制图脚本

完整说明见 `地图/` 目录下的 [地图制作指南.md](../地图制作指南.md)。所有命令都在 `地图/` 目录下运行。

## 运行顺序

| 步骤 | 脚本 | 产出 |
|---|---|---|
| 1 | `../数据/_生成地点规则.py` | `数据/地点规则.csv`（71 个地点的定位规则，**改地点改这个文件**） |
| 2 | `11_三海连通填充.py` | `产出/三海掩膜.npz`（各水体掩膜；北方海水位 `BOREALIS_LEVEL`） |
| 3 | `12_导出海岸线.py` | `产出/海岸线_2100.gpkg`、`.geojson`、`海岸线_多级海侵.geojson` |
| 4 | `20_地点定位.py` | `数据/火星地点.csv`、`数据/火星山峰.csv`、`产出/地点_2100.geojson`、`产出/基础设施_2100.geojson` |
| 5 | `21_生成对照表.py` | 刷新 `火星坐标对照表.md` 里的表格 |
| 6 | `30_水手峡谷战区图.py` | `产出/水手峡谷战区图_2100.svg` / `.png` |
| 7 | `31_火星全图.py` | `产出/火星全图_摩尔威德_2100`、`产出/火星全图_等距圆柱_2100`（`.svg` / `.png`） |
| 8 | `32_尺度对比图.py` | `产出/火星尺度对比图_2100`（另读 `数据/地球/` 的 Natural Earth） |
| 9 | `33_地形剖面图.py` | `产出/地形剖面图_2100` |
| 10 | `34_北方海极区图.py` | `产出/北方海极区图_2100` |
| 11 | `35_塔西斯区域图.py` | `产出/塔西斯区域图_2100` |
| 12 | `36_海拉斯区域图.py` | `产出/海拉斯区域图_2100`（含水文：径流水道、集水区、预测岸线） |
| 13 | `37_路线图.py` | `产出/路线图_2198`、`产出/路线_2198.geojson`（2198 年小说路线：海路、河、高原三段在真实地形上的最小代价路径 + 剖面） |
| 14 | `38_废井站导航图.py` | `产出/废井站导航图_2198`（序章导航屏：CTX 实景底图 + MOLA 等深线；瓦片缺了会联网下载到 `DEM/CTX缓存/`；依赖 37 的 geojson） |

```bash
./.venv/bin/python 数据/_生成地点规则.py
for s in 11_三海连通填充 12_导出海岸线 20_地点定位 21_生成对照表 30_水手峡谷战区图 31_火星全图 \
         32_尺度对比图 33_地形剖面图 34_北方海极区图 35_塔西斯区域图 36_海拉斯区域图 37_路线图 38_废井站导航图; do
  ./.venv/bin/python scripts/$s.py || break
done
```

## 其他

- `制图公共.py`：30–36 共用的配色、投影（等距圆柱、摩尔威德、墨卡托、方位投影）、晕渲、等高线、SVG、注记避让、比例尺、色标、图幅索引。
- 30–36 只读数据、不改数据，可以单独重跑任意一张；32 以后第一次运行会自动生成 `DEM/dem_32ppd_avg.npy`。
- `10_MOLA海平面标定.py`：DEM 自检与单阈值扫描，诊断用，不产出文件。
- `01_抽取海岸线.py` → potrace → `02_绘制海图.py`：按正典 p22 原图描的纸质海图版（`产出/水手峡谷海图.svg`）。
- `../旧版_HUD/`：Gemini 做的深色 HUD 版脚本和图，已停用。
