## 一、TS 原书的笔法

原书每章开头都有一小段小说，不到三百词。读了七段，共性如下。

### 1.1 七段样本

| 出处 | 内容 | 学什么 |
|---|---|---|
| ITW p.37 俱乐部（Deirdre Dachshund） | 第一人称，两个人在酒吧聊一首流行歌里埋了几层模因 | 模因学当酒吧闲话讲；商标名当地名用（Nataku、Colonial Genetics、Triplanetary）；结尾一句冷的：「我恨的是信息，不是媒介。走，跳舞去。」 |
| TS 核心书装备章开头（Casey 起床） | 侦探早上起床：地毯来蹭她，微型机器人群把她洗干净，虚拟界面报邮件 | 技术是家具，物件自己会动；短句陈述；AI 欢快，人不耐烦；型号随口报（Staub Buster、Klusterkorp skullcat、Euphrates 地毯） |
| ITW p.112 守护熊新闻 | 八岁女孩的 500 磅守护熊打退三合会入室者 | 新闻体，四句讲完；熊只说三个字「Chi-Chi stop bad man」；记者补一句「我们觉得这就够了」 |
| ITW p.77 太阳教会 | 祷文一问一答重复六遍，然后牧师心里一句「我不知道还能撑多久」 | 重复造节奏，最后一句翻转，不解释 |
| Broken Dreams p.25 《重返瓦尔登》 | 第一人称随笔，「他们说……他们说……」 | 排比是模因的节奏；说话人反而是被劝的那个 |
| ITW p.100 黑龙号演习 | 《新上海观察报》一段：舰长下令，陆战队跳向彗星，「只是演习？今天是。」 | 报纸腔当调味；先动作，后一句干的 |
| TM 社交过滤（Frida 与 Max） | 「出声：……　心里：……」两行交替 | 人和自己的 AI 对话有固定排版，不解释 |

### 1.2 归纳出的规矩

1. 技术是家具。不介绍，直接用。用商标、型号、条款号。
2. 本地人把怪事当日常。会惊讶的只有外来者。序章里外来者是她。
3. 叙述短，对话长。对话推剧情，叙述只给物件和动作。
4. 名词要具体，动词要实，形容词少，副词几乎不用。
5. 每段最后一句是干的，不抒情，不总结，不升华。
6. 数字只在有用时出现，而且是随口说的。「比这条船还值钱」比「二十万」好。
7. 幽默是冷的，从制度和物件里来。无神论者联盟起诉伴读厂商；「火星咖啡」在地球上是「难喝的咖啡」的代名词。
8. 原书爱用报纸、条款、广告、祷文这类「文件」当引子。序章的两段引言是对的路子，正文里可以继续用：一张塑封的录取信，一条产品条款，一份雇佣合同。

### 1.3 第二个参照：《To the Stars》的笔法

Hieronym 的《To the Stars》（AO3 作品 777002），你 2026-09-13 指定的参照。读了第一章（约一万五千词），量了一遍，规矩如下。

**它和 TS 一样的地方**：每章开头两三段公文（教师守则节录、配给机器的建议书），各六十到一百二十词，只给出处不解释；技术是家具；结尾一句干的。序章卷首那两段就是这个路子。

**它比 TS 多出来的东西**，也就是这次要往序章里加的：

| 规矩 | 原文的例子 | 中文里怎么做 |
|---|---|---|
| 贴身第三人称，人物自己的嘀咕直接进叙述，不加「她想」 | Ah well, it hadn't been worth setting an alarm. / Anything else would be inhuman, after all. | 「照这个亮度，大概是下午，也可能是上午。」 |
| 技术从习惯里出来，写的是动作，不是原理 | instinctively querying her chronometer. It was 10:11:23, it seemed, the knowledge injecting itself into her stream of consciousness / She ordered her blinds open with a thought / letting her bedsheets make themselves | 序章反着用：习惯还在，回应没了。「她查了一下时间。什么都没浮出来。」 |
| 解释可以写长，但要挂在人物的态度上（羡慕、无聊、渴望），末尾一句反讽 | 一整段讲成年人不睡觉，收在 Anything else would be inhuman, after all. | 「三个问题排着队，窗口关着。」 |
| 情绪直说，但只给一句 | She looked at it with longing. / But not her. She wasn't happy here. | 「她是地球人。」单独成段 |
| 一句成段当节拍器 | It didn't feel perfect to her. / Nothing at all. | 一场三到五处，不能更多 |
| 心里的话和出口的话分行 | Easy to nag when you don't have to sleep, Ryouko thought, but said out loud: "Alright, I'm coming." | 「记得。她在心里答了。嘴没跟上。」 |
| 口头禅：it seemed、after all、or something like that、nowadays | 每千词几处，给叙述一点人的温度 | 大概、按理说、反正、以前 |

**数字**（第一章正文）：句子平均 14 词，中位 12；三分之一的句子不到 8 词，超过 30 词的只有 6%。段落平均 23 词，**一半的段落只有一句**。对话占段落的 35%，每段 20 词。它用破折号做插入语（每千词 5 个），我们不用，改逗号或另起一句。

**中文版**（tts.liuli.moe，第一章《许愿》，你 2026-09-13 给的）。中文译文才是我们真正该对齐的节奏，量出来是这样：叙述句平均 23.5 字，中位 20 字；十字以内的短句占两成，四十字以上的长句占一成二；三分之一的段落只有一句。序章改稿前叙述句平均 18 字、长句只占 4%，比它碎；第二遍把四段解释性的句子接长了，现在平均 19 字，长句占 6%。对话多的场面本来就该比它碎一点，够了。

译文里几个可以直接学的做法：

- 心里的话不加引号，句号收，后面直接接「良子想」或接动作：「说得轻巧，你倒是不用睡觉。良子一边想着，一边回答：」「走吧。良子想，也许一百年后，我也会去追随你的脚步。」
- 一句成段的节拍：「没有任何事情。」「但她不是。她并不满足。」「良子感到事情有些不太对劲。」
- 口语连接词的用量，一万五千字里：其实 18、毕竟 13、反正 11、嘛 7、说实话 4、大概 4、算了 2。这些词是叙述里「人的声音」，序章用了算了、其实、反正、毕竟各一次，够了，再多就油。
- 长句的写法是逗号一路接下去，一件事说完才用句号：「考虑到大部分人的收入都来自于政府分配，城市与郊区之间的物价差距反映的多是物流成本，离市内的生产中心越远，东西就越贵。」
- 出处行译作「——摘自《通用中学教师守则 (第12版)》」。我们不用破折号，写成「《……》第 7 条。」，效果一样。
- 译文的破折号每千字 2.4 个，全是插入语。照 §3.1 的规矩，插入语用逗号，或另起一句。

**对话**（同一章中文版量的）：对话占段落的 36%；每段引号里平均 27 字，中位 18 字，三分之一不到十字，四分之一超过四十字。九成的对话段有标签，标签动词基本只有「说」和「问」，偶尔一个「反驳」「指出」「命令道」。**一半的对话段是拆开的**：先一句短的，接「某某说，」加一个动作，再接下半句。对话段之间夹了八十多条一句话的叙述，全是动作或语气。

| 规矩 | 译文的例子 | 序章里怎么做 |
|---|---|---|
| 拆句加标签，标签后面带一个同时发生的动作 | 「有时候我挺怀念以前的日子的。」杏子说，「只有我们四个人……」/ 她抿着茶说 / 杏子说着，移开了视线 | 「她运气好。」歪鼻梁说，把补给箱的盖子踢上，「在废井站那堆残骸里……」 |
| 两句话之间放一个动作节拍，一句成段 | 麻美摇了摇头。/ 杏子叹了口气，抬头看着天花板。/ 她清了清嗓子。/ 千秋翻了个白眼。 | 他等了一下，没有催。/ 第三张脸一直没说话，这时候朝舱前头偏了偏头。 |
| 语气可以直说，但只给几个字，一场一两次 | 语气中不带责备 / 语气中露出苦涩 / 她的话里带着讽刺 / 她对女儿很不满 | 话里没有恶意，酸味是有的。 |
| 听的人心里的反应插在两句之间，不加引号 | 站着说话不腰疼。你有魔法翅膀可以飞，当然觉得别人慢了。/ 她多半是知道的。 | 两个字说得很快，像关一扇门。 |
| 想说的和说出来的不一样 | 「我真的很想去。」麻美一边微笑回答，一边想着自己其实一点也不想去。 | 她本来想问的是这是哪儿。出口的是另一句。 |
| 问题可以用动作答 | 「有焰的消息吗？」…… 麻美摇了摇头。「当然没有。」她抿着茶说。 | 「你猜谁的账？」「别猜。」 |
| 一场只准一段长话，其余都短 | 西蒙娜讲一元文化那一段 | 团长讲野战急救单元那一段 |
| 说话人可以说到一半停下，叙述接管 | 「其实。」西蒙娜说，「我还有别的话想对你说。」 | 不用破折号断句，写「他说到一半停下来」 |
| 机器和人的对话不加引号 | 丘比的念话：「不，麻美，我们没有。它答道。」 | 熊修好以后说话，照这个格式，不加引号 |
| 对话中间可以停下来讲三百字背景，再用一句「好吧」接回去 | 悲叹立方审计那一段 | 序章没用；正文可以用，一场最多一次 |

对话本身的口语：呃、噢、嘛、反正、其实、算了都进引号，火星汉语那套（用词表 §2.3）照旧。

**2026-09-13 第二次改稿的教训**（读了 TtS 第二章之后）：第一版序章的毛病是「干」，原因五条，改稿时逐条对着看。

| 毛病 | TtS 怎么做 | 序章怎么改 |
|---|---|---|
| POV 人物不要任何东西，只被讲述 | 每条线第一句交代人物要什么，之后每段推它 | 她要熊、要终端、要一个年份，每样都开口去要，要到或要不到 |
| 叙述只记录不判断 | 八成是人物打分，两成是物件 | 每样物件一句实写，后面跟她一句打分（营养膏印草莓、游戏里才有三张一样的脸） |
| 情绪全用否定写（听不懂、想不起、没浮出来） | 正面状态：害怕、讨厌、肮脏、爽、笨 | 想生气、想笑没笑出来、把脸藏进兜帽 |
| 对话她听不懂，读者听懂了，对话不改变她 | 没有一句人物接不住的话 | 断眉用蹩脚英文当面说；汉语只写她听出的语气；团长翻译比原话客气，她察觉 |
| 没有时钟，没有人对她有议程 | 「不赶快仗就打完了」；杏子逼，麻美骗 | 「天黑前到站」；断眉当面估价，「总有人付」 |

物件描写仍照 TS，一句实写不动，判断句跟在后面。信息拆开给（名、信、系、年份各一行，每行她有反应），大的数字让她自己算出来（2186 到 2198，三年过去了四次）。

**章末注的规矩**（2026-09-13 定）：每章末尾一组注，标题「X 章注」，百科体，只解释本章已经出现过的名词。注只讲「怎么工作」（静止舱四小时、山羊为什么会跳、海为什么在北边），「归谁、为什么死、后果是什么」留给书里有动机说它的人。注里不出现任何势力的名字，势力按路线顺序在正文里出场。从注里撤下来的话记在 势力名录.md §10，写到那儿从那里取。

**两个参照怎么合**：物件照 TS 写，人照 TtS 写。TS 管家具和干的结尾，TtS 管人物的内心声音和「按理说」的落差。序章 2026-09-13 的改稿就是这么改的：动作和物件一句没动，加的全是她的习惯、她的比较、她心里没说出口的话。

### 1.4 第三个参照：两本网文（2026-09-13 第三次改稿）

你给的两本：《星蓝摇曳》（wearecr，科幻军事，2010 年代论坛连载）和一本星盟造船厂实习生开头的工业流科幻（林夜，章末带【名词】表）。加上 TtS 中译本，三本是同一种耳朵：网文和轻小说的耳朵。这本书是这个类型的科幻，主视角固定，人不轻，但腔调按这三本来，不按文艺小说来。第三稿序章照此改，规矩如下：

| 规矩 | 参照里的样子 | 序章里怎么做 |
|---|---|---|
| 视角管「看见什么」，叙述者管「这是什么」 | 林夜坐平台上升，叙述者顺手讲星铸炉和建造中心 | 她不知道船的来历，叙述者照讲；她不知道年轮怎么来的，团长说一句，叙述者补一段 |
| 句子靠逗号走，一段一口气，一件事说完才用句号 | 「驾轻就熟地穿过一段严重变形的舱道，又轻巧地避开……几番转折之后，姬蓝霖终于进入了卧室。」 | 叙述句平均 24 字，四十字以上占两成多。短句留给对话和节拍 |
| 连接词不吝啬 | 虽然、不过、反正、毕竟、其实、所以 | 放回去，读者不用自己接因果 |
| 心里话直接进叙述，口语，可以吐槽 | 「力气没对方大心思没对方细智商没对方高也就罢了」「薪水小偷」「请个神父开个光」 | 「火星人大概觉得装了也没人信」「这会儿连今天星期几都得靠猜」 |
| 说话后面带反应，不单起一段押金句 | 「恨恨地跺了跺脚」「无奈道」 | 反应缩回说话尾巴；段尾金句一场砍到三四个 |
| 世界从活儿里出来 | 实习生修无人机、遥控工作路径 | 她得填一张纸：名字、系、付钱的人、最后的日子。填的过程就是算十二年 |
| 章末名词表带语气，可以指回正文 | 「虽然听上去很霸气，实际上主要是生产常规材料的」「可惜，这是针对……的待遇」 | 序章注每条末尾允许一句编者的话，允许「序章里……就是」 |
| 不学的 | 形容词堆外貌；「竟、却」满篇；「射成了筛子」一章三次；标点一逗到底 | 形容词照 §1.2 第 4 条；套话全文搜 |

## 三、禁用清单

> 2026-09-13 改口：下面这些不是不能用，是要用得合理（你的原话：「AI 味没必要硬吃」）。破折号仍不用。其余每条的意思是「别成习惯」，一场里出现一两次、出现得有理由，不算错；自查时数的是密度，不是有无。真正要躲的是套话：同一个漂亮句式在一章里反复，段段结尾押金句，叙述者躲着不解释。


### 3.1 标点

- 不用破折号（——）。解释就另起一句，插入用逗号，引言出处用句号收。
- 少用分号。两句就写两句。
- 省略号只给说话人，一场最多两次。
- 不用感叹号。

### 3.2 AI 常见句式与替换法

| 禁用 | 为什么 | 换成 |
|---|---|---|
| 不是……而是…… | 替读者下判断 | 只写「是」的那一半 |
| 像在……／像是在……／仿佛在…… 后面接心理揣测（「像在核对反应」） | 替人物解释动机 | 写动作本身：蹲下，手放膝盖上 |
| 某种……（「某种不耐烦的谨慎」） | 不敢说清 | 说清，或删 |
| 带着……的克制／短促而克制 | 抽象形容 | 写克制的动作：揉两下，手收回去 |
| 一丝／一抹／一缕 | 装饰量词 | 删 |
| 空气中弥漫着／气氛变得 | 叙述者抒情 | 写具体的味道或声音 |
| 这一刻／那一刻／在这个瞬间 | 假强调 | 删 |
| 她知道……／她意识到……／她明白了 | 告诉而非展示 | 写她做了什么 |
| 不由得／不禁／忍不住（叙述里） | 副词填充 | 删；对话里可留一次 |
| 三项并列的排比（轻蔑、调侃、谨慎） | 凑数 | 两项，或一项 |
| 段尾格言 | 升华 | 一场只准一句，放人物嘴里，不放叙述里 |
| 值得注意的是／某种意义上／本质上 | 论文腔 | 删 |
| 沉默／寂静／压抑 当名词用 | 抽象 | 写剩下的声音：履带碾冰一下又一下 |
| 目光扫过／眼神里 | 万能动作 | 写他看哪儿，看多久 |
| 语气里带着……的……（长的） | 抽象堆砌 | 允许一个短的：「语气里没有责备」，一场最多两次（§1.3 对话） |
| 仿佛 | 每千字最多一次 | 「像」加实物 |
| 同一形容词一场重复三次 | 惯性 | 写完全文搜一遍 |

### 3.3 写完自查

1. 全文搜：「——」（必须为零）；「仿佛」「某种」「一丝」「克制」「意识到」「这一刻」「不是」（数密度，一场超过两次再改）。
2. 数段尾金句，一场超过四个就砍。
6. 数一句成段的叙述（不算对话），一场超过十个就并回上一段。
7. 连接词够不够：虽然、不过、反正、毕竟、所以。一千字里一个都没有，说明又写干了。
3. 每个「像」后面接的是不是实物。不是就改。
4. 数叙述里的副词。
5. 每个配角至少有一个可见的区别（伤疤、动作）。不写「其中一人」。
