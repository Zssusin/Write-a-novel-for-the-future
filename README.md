# 《Write a novel for the future》小说创作与世界观工程库

本分支（`novel`）是硬科幻小说（2198 年火星）的手稿、设定与制图工程的备份分支。博客在 `main`，Transhuman Space 原书资料另有 `materials/ts` 分支。

## 目录结构

```
.
├── 目录说明.md               # 各文件夹放什么
├── 正文/                     # 小说正文与写作规范
│   ├── 序章_新稿.md            # 新序章（2184 加里宁格勒，丹妮丝；2026-09-18 按 TtS 炼化手册重写，末场待写）
│   ├── 序章.md                 # 旧序章（2198 北方海，可能降为第一章；人名、伴读、专业尚未与新稿同步）
│   ├── 序章审校.md             # 对照正典的审校记录
│   ├── 写作用词表.md           # 笔法、用词、禁用清单，写完按 §3.3 自查
│   ├── TtS炼化手册.md          # 《To the Stars》中译第一卷 39 万字量出来的段落配方、心理描写、时代感、词频与书单
│   └── 旧稿/                   # 新序章的历次版本与摘下来的场次
├── 设定/                     # 世界设定
│   ├── 2198 主题设定.md        # 主时点、年表、待定清单
│   ├── 势力名录.md             # 沿路线的势力，§10 是留给正文说的话
│   ├── 路线_北方海到火大.md    # 三程路线与里程（海路 3,355 km，全程 9,460 km）
│   ├── 火星战争卷宗.md         # 2100 年的军事与社会底本
│   ├── 火星据点大全.md         # 所有城市与据点
│   ├── 火星环境与尺度.md       # 环境数据，用地球参照物讲尺寸
│   └── 火星坐标对照表.md       # 地点坐标与高程（由脚本生成）
├── 地图/                     # 制图工程
│   ├── 地图制作指南.md         # 制图规范、流程、坑

└── 图片待上传/               # 博客插图
```

## 不入库的东西

- `地图/DEM/`：MOLA 463 m 高程栅格（2 GB）、TES 反照率栅格（16 MB，USGS 下载）、32 ppd 与反照率缓存、CTX 影像瓦片缓存。脚本缺了会自己下或自己算。
- `地图/.venv/`、`地图/bin/`：本机 Python 环境与 GDAL flatpak 垫片，见指南「环境」一节。
- `资料/TS/*.pdf`：规则书原件，本地保留，入库的是文字提取版。
